# Bitrix

Каталог содержит только два файла, необходимые штатному компоненту:

- `component.php` — входная точка компонента;
- `template.php` — iframe целевого виджета и передача анонимных событий.

Скопируйте их в `/local/components/vodc/chatbot/` и задайте `SERVER_URL`,
указывающий на HTTPS origin чат-сервиса, например `https://chat.vodc.ru`.

Старый прямой вызов `/chat` не поддерживается. События воронки приходят через
`postMessage`; родительская страница может отправлять их в Яндекс Метрику без
текста и персональных данных.
