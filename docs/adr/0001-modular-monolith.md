# ADR-0001: Модульный монолит FastAPI

- Статус: принято
- Дата: 2026-07-29

## Контекст

MVP разрабатывает небольшая команда за восемь недель. Нужны API, SSE,
оркестрация, RAG, интеграция с МИС и фоновые задачи. Независимое
масштабирование доменных сервисов на первом релизе не требуется.

## Решение

Использовать один deployable backend FastAPI и worker из той же кодовой базы.
Внутри сохраняются жёсткие модульные границы:

- `domain` — чистые бизнес-правила;
- `ports` — контракты зависимостей;
- `orchestrator` — use cases;
- `adapters` — внешние системы;
- `main` и `container` — HTTP и composition root.

PostgreSQL, Redis, vLLM и МИС остаются отдельными процессами.

## Последствия

- один release и простой rollback;
- транзакции и наблюдаемость не распределены между микросервисами;
- доменную логику можно тестировать без инфраструктуры;
- выделение сервиса возможно позднее по существующему порту;
- запрещены прямые импорты адаптеров из domain, ports, orchestrator и main;
  правило контролирует `scripts/check_architecture.py`.
