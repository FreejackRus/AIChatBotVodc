# ADR-0002: Детерминированная воронка и safety до LLM

- Статус: принято
- Дата: 2026-07-29

## Контекст

LLM не является надёжным механизмом авторизации инструментов, переходов
воронки и медицинских ограничений. Ошибка может привести к выдуманному слоту,
медицинской рекомендации или вызову МИС с неподтверждённым идентификатором.

## Решение

Safety gateway выполняется до intent-классификации, RAG, LLM и МИС.
Intent-классификация и state machine детерминированы. LLM используется только
для формулировки статического ответа по утверждённым источникам.

Цена, врач, филиал и слот выводятся из МИС карточками. Действия карточек
подписаны HMAC, привязаны к сессии и повторно проверяются в МИС. Backend не
создаёт, не переносит и не отменяет запись.

## Последствия

- критические правила покрываются обычными unit-тестами;
- prompt injection не расширяет права инструментов;
- динамические ответы менее свободны, но воспроизводимы;
- расширение нового сценария требует явного intent, перехода и policy.
