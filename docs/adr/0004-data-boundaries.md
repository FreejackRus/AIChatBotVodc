# ADR-0004: Разделение raw, обезличенных и динамических данных

- Статус: принято
- Дата: 2026-07-29

## Контекст

Диалог может содержать ПДн и медицинские сведения. Для отладки нужны
ограниченные обезличенные данные, а цены и расписание быстро устаревают.

## Решение

- raw-текст хранится только в Redis с TTL 2 часа и без persistence;
- PostgreSQL получает только результат локального redaction;
- обезличенные сообщения и события удаляются через 90 дней;
- Метрика получает только allowlisted события и свойства;
- RAG хранит утверждённые статические источники;
- цена, врач и слот всегда запрашиваются из МИС;
- cache каталогов МИС — до 5 минут, слотов — до 30 секунд.

## Последствия

- перезапуск Redis намеренно уничтожает активные raw-сессии;
- аналитика не поддерживает полную атрибуцию записи;
- восстановить исходный текст из PostgreSQL невозможно;
- недоступность МИС приводит к safe fallback, а не к данным из RAG.
